# Правила проекта

## Комментарии в коде
Комментировать по ходу работы, без напоминаний. Комментарий объясняет **зачем**, а не что:
почему такое решение, какое ограничение оно обходит, что сломается иначе. Не описывать то,
что видно из кода. По-русски, перед блоком.

Обязательно комментировать: стадии и состояния (что откуда выводится), расчёты денег,
решения по безопасности и индексации, ограничения масштаба, любое место, где два экрана
должны говорить одно и то же.

## Дизайн
- Дизайн-система Industry, светлая и тёмная темы.
- Приглушённый текст — не ниже 68 % от `--color-text` (50–55 % не проходят по контрасту).
- Красный только для критичного, предупреждения стальные.
- Не использовать `--space-5` — такого токена в Industry нет.
- Ширины колонок таблиц задавать на `th`, а не через `colgroup` — он вырезается из DOM.
- Радиокнопки с предвыбором: `defaultChecked="{{ true }}"`, иначе состояние не отрисуется.

## Продукт
- Аудит бесплатный, оплата за фактический объём правок. Подписок и пакетов нет.
- Деньги в холде до одобрения превью.
- Не выдумывать метрики («+N % трафика» и прочее) — только измеримое.
- Обещания не должны расходиться между лендингом, кабинетом и админкой.
