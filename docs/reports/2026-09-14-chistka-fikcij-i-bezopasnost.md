# SeoMarket: восстановлена защита данных, из интерфейса убрана фикция

**Дата:** 14 сентября 2026
**Ветка:** `fix/inject-not-rebuild` → [PR #4](https://github.com/Alex1986-rgb/seomagic-saas-tool/pull/4)
**Решение по платформе:** остаёмся на Supabase.

## Главное: дыра в безопасности

Миграция от 18.11.2025 с заголовком «⚠️ TESTING MODE ONLY — MUST BE REVERTED BEFORE
PRODUCTION» заменила политики двенадцати таблиц на `USING (true)`. Откат так и не сделали,
поэтому до сих пор:

- любой посетитель, **даже не авторизованный**, мог читать, менять и удалять **чужие аудиты**;
- таблица `profiles` с почтой и именами была открыта всем;
- вставка строки в `user_roles` была разрешена кому угодно — **любой мог сделать себя
  администратором** и войти в админку.

Миграция `20260914150000_revert_testing_mode_rls.sql` возвращает доступ владельцу записи:
роли выдаёт только администратор, служебная очередь обхода закрыта полностью, анонимные
быстрые аудиты с главной остаются общедоступными — как было задумано до «тестового режима».

**Применить обязательно до того, как сайтом начнут пользоваться посторонние.**

## Ключ поставщика выдачи

XMLRiver принят и проверен живьём: баланс 995,4 ₽, Google и Яндекс отвечают. По ходу
проверки вскрылись три расхождения кода с реальным API — исправлены:

- брались все ссылки подряд, включая рекламу, — позиция уезжала вниз;
- штатная ошибка 500 «выполните перезапрос» считалась сбоем, хотя приходит примерно
  через раз — теперь до трёх повторов;
- глубина запрашивалась параметром `groupby`, который её не меняет: приходило 10 позиций
  вместо 100 — теперь глубина добирается постранично.

Ключ лежит в `~/.claude/secrets/seomarket.env`, в репозиторий не попал.

## Кабинет и админка — на реальных данных

| Было | Стало |
|---|---|
| Кабинет: вписанные в код цифры, чужие сайты `example.com`, `mysite.ru`, «активность команды» с несуществующими людьми | Обзор, аналитика, отчёты и сайты считаются по своим аудитам, позициям и оптимизациям |
| Админка → Платежи: список выдуманных транзакций | Честное «приём оплаты не подключён» — платёжной системы в продукте нет |
| Админка → Аналитика: «3 842 аудита», «642 пользователя», «доход ₽512 400» | Аудиты, пользователи, проверки позиций, задания оптимизации из базы; аудиты по дням, статусы, самые проверяемые сайты |
| Админка → Аудиты: пять выдуманных строк | Реальные записи всех пользователей, поиск, фильтр, обновление, выгрузка CSV |
| Пять «инструментов» (битые ссылки, дубликаты, структура сайта, уникальность, PageRank), выдававших заранее написанные результаты для любого домена | Удалены. Данные такого рода собирает настоящий аудит |

Итого убрано 1935 строк имитаций.
