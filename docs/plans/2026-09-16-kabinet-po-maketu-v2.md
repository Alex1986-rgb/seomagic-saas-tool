# Кабинет SeoMarket 2.0 по макету Claude Design — 16.09.2026

Источник: handoff-архив «SeoMagic tool planning», файл `SeoMarket v2.dc.html` (копия — `design/seomarket-v2/`).
Макет: 20 экранов кабинета и админки, дизайн-система Industry, светлая и тёмная темы.

## Решения

1. **Новый кабинет живёт на `/app/*` параллельно старому.** Старые `/dashboard`, `/site-audit`,
   `/reports` и т.д. не ломаем, пока новый не принят; потом — переадресация и удаление дублей.
2. **Industry подключается только внутри кабинета**: токены и классы в `src/cabinet/styles/industry.css`
   под `html.ds-industry`. Публичный сайт (718 файлов, тёмная тема) не перекрашивается — это отдельный этап.
3. **Только настоящие данные.** Макет нарисован на выдуманном mebel-grad.ru. В коде — данные из Supabase;
   где бэкенда нет (оплата и холд, исправление копии, конкуренты, частотность, CWV, платежи, хостинг,
   метрики сервера) экран сверстан, но честно показывает «не подключено», без цифр-заглушек.
4. **Прокси в админке → «Поставщик выдачи»** (XMLRiver): прокси в проекте не используются.
5. Шрифты Barlow / Barlow Condensed — с собственного хостинга (`@fontsource`), не Google Fonts.

## Этапы

1. Фундамент: `industry.css` (токены, тёмная тема, классы макета), шрифты, примитивы
   `src/cabinet/ui.tsx`, иконки, оболочка с сайдбаром и шапкой, маршруты `/app/*` под входом.
2. Экраны — пять исполнителей параллельно, у каждого свои файлы:
   - A: Обзор, Первый вход, Новый аудит, Результаты, Страница;
   - B: Оптимизация, Смета (общий расчёт), Исправление, Оплата, Смета по ссылке;
   - C: Позиции, Конкуренты, История, Отчёты, Уведомления;
   - D: Настройки, Добавить сайт, Вход, Сброс пароля;
   - E: Админка (Сводка, Цены, Очередь, Платежи, Поставщик выдачи, Хостинг, Система).
3. Сборка: типы, тесты, сборка, проверка в браузере в обеих темах и на ширине телефона.
4. Отчёт `docs/reports/2026-09-16-kabinet-po-maketu-v2.md`, память.

## Не входит

Публичные страницы (лендинг, блог, отзывы, документы), письма, бэкенд оплаты и исправления копии —
отдельные планы. Выкладка на Pages — только по явному «да».
