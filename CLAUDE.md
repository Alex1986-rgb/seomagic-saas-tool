# SeoMarket (seomagic-saas-tool) — Обзор

SaaS-платформа SEO-аудита и оптимизации сайтов. GitHub: `Alex1986-rgb/seomagic-saas-tool`.

## Стек и команды

React + Vite + TypeScript + shadcn/ui + Tailwind; пакетный менеджер — **bun** (`bun.lockb`).

```bash
bun install        # зависимости
bun run dev        # dev-сервер Vite
bun run build      # прод-сборка
bun run lint       # eslint
```

## Состояние проекта (важно)

- **Аудит сайта — реальная функциональность.**
- **Трекинг позиций — реальный** (сентябрь 2026): выдачу отдаёт внешний поставщик
  через edge-функцию `positions-check`, результаты лежат в `position_checks` /
  `position_results`. Ключи поставщика — в секретах Supabase, см. `docs/POSITION_TRACKING.md`.
  Без ключей раздел честно отказывается работать, чисел не выдумывает.
- **ИИ-оптимизация — реальная** (сентябрь 2026): `seoOptimizationController` ведёт
  цепочку `audit-start → audit-status → optimization-start → optimization-status`.
  Тексты пишет **DeepSeek** (`deepseek-flash`) через общий слой
  `supabase/functions/_shared/llm.ts`; поставщик переключается переменной
  `LLM_PROVIDER` (`deepseek` / `anthropic`), ход рассуждений модели в ответ не
  попадает. Сборка исправленной копии сайта на сервере пока не реализована —
  интерфейс об этом честно сообщает.
- **Личный кабинет** переведён на настоящие данные 16.09.2026: история аудитов, позиции,
  отчёты и уведомления читаются из базы, пустые состояния честные. Подписки и тарифов нет —
  приём оплаты не подключён, вместо него заявка на счёт в таблицу `contact_requests`
  (раздел «Заявки» в админке).
- Прежде чем «чинить» фичу, проверь, не мок ли она. Разбор того, что было выдумано и как
  починено, — `docs/reports/2026-09-16-perepoverka-i-dorabotka.md`.

## Грабли, на которые уже наступали

- **Не возвращать `manualChunks` в `vite.config.ts`**: правило `id.includes('react')` ловило
  `@radix-ui/react-*` и создавало циклические части — собранный сайт открывался пустым
  с `createContext undefined`.
- **`react-helmet-async` нужен версии 2.x**: на 1.3 с React 18 в строгом режиме метатеги
  молча не вставляются. Заголовок и описание страницы задаются компонентом `PageSeo`.
- **Сайт публикуется на подпути** `/seomagic-saas-tool/`. `base` берётся из `VITE_BASE_PATH`,
  по умолчанию подпуть; роутер работает с `basename`, сборка кладёт `404.html`.
- **Не собирать карточные данные**: приём платежей не подключён. Формы просят почту и
  оставляют заявку на счёт.
- **Контакты — только из `src/config/site-contacts.ts`**. Пустое поле означает «не показывать»;
  выдуманные адрес, телефон и отзывы в разметке schema.org приводят к санкциям поисковиков.
- **Числа на экране — только измеренные.** Если данных нет, показываем пустое состояние,
  а не «примерные» значения: половина прежнего интерфейса состояла из таких подстановок.

## Рабочие процессы Claude Code

- **Параллельные сессии**: `claude --worktree <имя>` — отдельная копия репозитория на своей ветке; две задачи в двух терминалах, правки не сталкиваются. Локальные файлы вне гита, нужные для работы, перечислены в `.worktreeinclude` — они копируются в worktree автоматически.
- **План перед правками**: `Shift+Tab` до режима `plan` (или `claude --permission-mode plan`) — Claude сначала предлагает план и не трогает файлы до одобрения. Полезно для рискованных правок (деплой, массовые замены).
- **Субагенты для разведки**: «use a subagent to выяснить …» — чтение кода идёт в отдельном контексте, в диалог возвращается только вывод; основной контекст не засоряется.
- **Продолжение работы**: `claude --continue` — последняя сессия в этой папке; `claude --resume` — выбор из списка; `claude --from-pr <N>` — найти сессию, из которой родился PR (например, PR #2 с фиксами моков).
- **@-ссылки**: `@путь/файл` кладёт файл в контекст целиком, `@папка/` — листинг; по `@` работает автодополнение путей.
- **Пайпы (headless)**: `git log --oneline -20 | claude -p "суммаризуй"` — Claude как unix-утилита для скриптов и CI.
- **Задачи по расписанию**: Routines (claude.ai/code/routines — облако Anthropic, работает при выключенном Mac, триггеры по GitHub-событиям), scheduled tasks desktop-приложения (доступ к локальным файлам), GitHub Actions, `/loop` в открытой сессии.
